Добавил файл логов в volume и данные/ошибки пишутся в него. То есть работоспособность приложения можно проверить таким образом.<br>

Приложение работает с Кастомным сериализатором ClientSerializer и десериализатором ClientDeserializer.<br>

Создал класс Client, от него сделал экземпляр с тестовыми<br>
данными (аттрибуты clientId и name), сериализовал их и отправка происходит с помощью Producer.py<br>

Данные идут в топики по партициям и на них натравлены две группы консюмеров (по заданию)<br>
Первая консюмер группа - SingleGroup<br>
Вторая консюмер группа - BatchGroup<br>

Они забирают данные из топика по партициям (разные группы могут параллельно читать партиции, но в рамках одинаковой группы у них общие оффсеты)<br>
Десериализуют их и пишут в логи. Ошибки также ловятся и пишутся в логи<br>
Также ошибки сериализации пишутся в логи<br>



Проверить работоспособность приложения можно, выполнив docker-compose up -d схожим образом, как сделал я
